# Тесты

Только один способ запуска:

```bash
./tests/run.sh               # весь набор
./tests/run.sh -q -k store   # подмножество
```

Тесты гоняются **внутри Docker** (`linux/amd64`, `python:3.11-slim`). Локальный
python на macOS отрисует шрифты другой версией freetype, и эталоны разойдутся
на ровном месте. Платформа прибита к amd64: совпадает с продом на Railway и
между разработчиками.

## Что покрыто

- `test_render_golden.py` — 21 эталонная картинка по всем режимам, форматам,
  каналам и уровням затемнения. Сравнение попиксельное. Упавший тест кладёт
  свой результат в `tests/output/` — можно открыть и сравнить глазами.
- `test_fonts.py` — сторож: шрифты грузятся из корня репозитория, а не
  подменяются системным DejaVu.

Диалог, клавиатуры и рассылка эталонами **не покрыты** — проверяются руками
в Telegram.

## Исходники

`tests/fixtures/` — три кадра и лого партнёра, генерируются
`tests/make_fixtures.py` детерминированно, без единого случайного числа.

Намеренно без пиксельного шума: рендер реагирует на яркость участков кадра,
а не на зернистость. С шумом PNG не сжимался и фикстуры весили 17 МБ, а
эталоны потянули бы на сотни. Сейчас всё вместе — около 1 МБ.

## Эталоны

Сняты на монолитном `bot.py` (коммит `882295a`) до распила на модули, внутри
образа `python:3.11-slim` (Python 3.11.15, linux/amd64), Pillow 10.2.0,
numpy 1.26.4.

Тег `python:3.11-slim` подвижный. Если база обновится и принесёт другой
freetype, эталоны покраснеют без единой правки кода — это **повод переснять
эталоны, а не искать регрессию**. Отличить одно от другого просто: если
разошлись все картинки разом и только по краям глифов — это freetype.

Переснять:

```bash
GOLDEN_UPDATE=1 ./tests/run.sh
```

Никогда не делай этого, чтобы «починить» красный тест после правки кода
рендера, не разобравшись в причине.
